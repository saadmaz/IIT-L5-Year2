# Advanced Client-Side Development

## Week 02 - Tutorial – Exercise One

## 📌 Overview

This repository contains **Exercise One** from the **Advanced Client-Side Development** module.
The exercise focuses on building a **responsive, visually structured web page** using **HTML5 and CSS3**, with an emphasis on layout, styling, animations, and responsive design principles.

The project simulates a **travel accommodation platform landing page** called **“Musafir”**, showcasing destinations, accommodations, activities, and filtering options.

---

## 🎯 Objectives of the Exercise

The purpose of this tutorial exercise is to:

* Practice semantic HTML structure
* Apply modern CSS styling techniques
* Implement responsive layouts for mobile and desktop
* Use external libraries and assets correctly
* Introduce basic UI animations and loading states

---

## 🛠️ Technologies Used

* **HTML5** – Page structure and semantic layout
* **CSS3** – Styling, animations, and responsiveness
* **Normalize.css** – Cross-browser consistency
* **Google Fonts (Raleway)** – Typography
* **Font Awesome** – Icons
* **Media Queries** – Responsive design

## 🧱 Key Features Implemented

### 1. Page Loader Animation

* A circular **CSS-based loader** is displayed when the page loads
* Uses `@keyframes` for rotation and fade-out effects
* Main content fades and slides into view after loading

### 2. Header & Navigation

* Simple navigation bar with:

  * Logo branding
  * Navigation links
* Hover effects for better user interaction
* Mobile-friendly stacked navigation for smaller screens

### 3. Search Section

* Location-based search input
* Icon-enhanced input field
* Responsive search button that adapts for mobile view
* Filter options with icons and hover states

### 4. Accommodation Listings

* Grid-based card layout
* Images, titles, and pricing information
* Hover shadow effects for better UI feedback
* “Show more” button for future expansion

### 5. Popular Section

* Sidebar-style layout for popular accommodations
* Uses flexible box layout for image-text alignment
* Adjusts automatically for mobile screens

### 6. Activities Section

* Image-based activity cards
* Responsive grid system
* Clean and minimal presentation

### 7. Footer

* Structured footer with:

  * About section
  * Accommodation information
  * Assistance links
* Fully responsive grid layout

---

## 📱 Responsive Design

The layout adapts to smaller screens using **CSS media queries**:

* Navigation collapses into stacked layout
* Grid layouts convert to single-column views
* Icons replace text where appropriate
* Footer switches to vertical alignment

Breakpoint used:

```css
@media (max-width: 768px)
```
